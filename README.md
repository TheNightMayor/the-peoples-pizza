# The people's pizza

A no-build, responsive brochure site for a traveling pizza popup.

## Updating the site

- **Menu:** edit the `menuItems` array at the top of `script.js`.
- **Calendar:** in `calendar.html`, replace `YOUR_GOOGLE_CALENDAR_ID` with the public Google Calendar ID. The calendar must be made public for the embed to work.
- **Contact/social links:** update the email address and Instagram URL in `script.js`.
- **Brand copy:** edit the HTML files directly; no framework or build step is required.

Open `index.html` locally, or deploy the folder to GitHub Pages, Netlify, Vercel, or any static host.
